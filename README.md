# ПРОМЕТР — сайт поверки счётчиков

Статический сайт на русском языке. Основные страницы: `/`, `/murmansk/`, `/simferopol/`, `/sevastopol/`. Структура основана на предоставленном сайте поверки-82.рф; дизайн и тексты новые. Единственный телефон: 8 (950) 565-71-41.

## Содержимое

Папка `dist` — готовый сайт без серверных зависимостей. Содержание страниц и разметка находятся непосредственно в HTML, доступны без JavaScript. JavaScript нужен только для калькулятора. FAQ работает без JavaScript. Изображения и стили локальные, внешние шрифты и трекеры не загружаются.

## Публикация на собственном домене

1. Указать окончательный HTTPS-адрес в `site-config.json`, поле `origin`. Для собственного домена использовать корень домена, не подкаталог репозитория.
2. Выполнить `node scripts/build-static.mjs`. Это обновит canonical, Open Graph, JSON-LD, sitemap и robots во всех страницах.
3. Загрузить содержимое `dist` в корень сайта. Для GitHub Pages можно опубликовать `dist` через Pages Actions и подключить собственный домен в настройках Pages; файл `.nojekyll` уже включён.
4. Включить HTTPS, выбрать один основной адрес (с www или без) и настроить постоянный редирект с альтернативы. Настроить редиректы `/город/index.html` → `/город/`, если платформа допускает их; canonical уже указывает на адрес с завершающим слешем.
5. Проверить, что несуществующий адрес возвращает настоящий HTTP 404 и страницу `404.html`, а не главную с кодом 200.
6. Открыть доступ для посетителей и поисковых роботов на выбранном публичном хостинге. Приватная версия Sites предназначена для просмотра владельцем и не заменяет публичный SEO-запуск.

## Перед продвижением

- Проверить текущий статус и область аккредитации в https://pub.fsa.gov.ru/ral по RA.RU.314482. Включённый аттестат предоставлен пользователем и датирован 8 июня 2023 года; действующий статус независимо не подтверждён.
- Подтвердить текущие тарифы, условия выезда и применимость цены 900 ₽ при четырёх приборах. Калькулятор применяет эту цену к обоим типам жилья, по указанному предложению; перед выездом цена подтверждается по телефону.
- Внести реальные часы работы и адреса обслуживания, если они будут предоставлены. Фиктивные городские офисы, отзывы, рейтинги, гарантии приезда и реквизиты не добавлены.
- Зарегистрировать публичный домен в Яндекс Вебмастере и Google Search Console; отправить `/sitemap.xml`. Добавить подтверждённые карточки компании там, где бизнес соответствует требованиям площадки.
- При подключении Яндекс Метрики или другой аналитики настроить цели на телефонные ссылки. На клик отправляется только локальное событие `prometr:call`; счётчик не подключён, данные наружу не передаются.
- Отслеживать индексацию трёх посадочных страниц, показы и заявки отдельно по городам. Техническая база не гарантирует позиции в выдаче.
